Clínica Veterinaria PataVerde

Proyecto de la Evaluación Parcial 2 de DSY1102 – Programación Orientada a Objetos.

Aplicación en Java 21 con JavaFX para registrar perros y gatos, calcular el costo de consulta y guardar los datos en "Mascotas.json" usando Gson.

Cómo ejecutar:

-Abrir el proyecto en IntelliJ IDEA.
-Ejecutar la clase "Launcher".
